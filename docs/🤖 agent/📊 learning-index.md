## Critical Learnings (Must Apply Always)

### 🔴 AL-001: TDD and Git Workflow Discipline
**When**: ALWAYS - Every feature, bug fix, code change
**What**: 
- Create feature branch BEFORE any code changes
- Write tests FIRST (red-green-refactor)
- Commit after EACH task completion
- "Quicker" means efficient process execution, NOT skipping process

**Why Critical**: Skipping these steps creates technical debt, makes rollback difficult, and violates Definition of Done
